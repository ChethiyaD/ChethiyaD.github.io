# 🚀 Quick Start Guide (5 Minutes)

## Start Right Now

### 1️⃣ Start Development Server (30 seconds)
```bash
cd "e:\My Projects\my-portfolio"
npm run dev
```
✅ Your site opens at http://localhost:3000

### 2️⃣ Make Your First Change (1 minute)
1. Open `src/components/Navigation.jsx`
2. Find line 25: `John Doe`
3. Replace with your name
4. **See it update instantly** in the browser! 🎉

### 3️⃣ Customize Key Sections (15 minutes)

**Your Name (5 places):**
- `src/components/Navigation.jsx` line 25
- `src/sections/Hero.jsx` line 28
- `src/components/Footer.jsx` line 28

**Your Tagline:**
- `src/sections/Hero.jsx` line 23

**Your Bio:**
- `src/sections/About.jsx` line 24-25

**Your Skills:**
- `src/sections/About.jsx` lines 39-48

**Your Projects:**
- `src/sections/Projects.jsx` lines 5-40

### 4️⃣ Test Locally (5 minutes)
- ✅ Refresh browser - changes appear instantly
- ✅ Test navigation links - scroll smoothly
- ✅ Test on mobile - resize browser window
- ✅ Check all links work

### 5️⃣ Ready to Deploy? (Build & Deploy - 10 minutes)
```bash
npm run build
```

Then deploy to **Netlify** in 3 steps:
1. Push to GitHub (5 min)
2. Go to netlify.com (30 sec)
3. Connect repository (1 min)
4. **Live! 🎉**
